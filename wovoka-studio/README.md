## Rules for this brand

The portfolio rules in the [top-level README](../README.md) apply. On top of them:

1. **Never name a client or a client's site.** Talk about the work the way the site does: what was built
   and what it does. Ask Lee before featuring anything made for someone else.
2. **Every figure has a source**: the repository, the database or the date it was counted. Lead with the
   work, then the stack.
3. **Plates say ROUTE or STOP, never EXIT.** To investors, "exit" means selling the company.
4. **The pattern is banig.** Do not borrow Indigenous textiles, such as T'nalak, as decoration.
