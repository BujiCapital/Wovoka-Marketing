# Template for a new brand folder

Copy this folder to `<brand>/` and fill in each file. Keep the file names and headings: tools such as
HeyGen find things by them. Use [`../carbon-supply/`](../carbon-supply/) as the worked example.

Before the pull request is merged, check that every line is already public on the brand's own website:
no unconfirmed figures, no client names, no prices or terms that are not published, no personal data.

| File | Fill in |
|---|---|
| `README.md` | The brand's own rules on top of the portfolio rules; the call to action; where to post; sizes |
| `product.md` | One line; what a customer gets; why it is different; what it is not; who makes it |
| `audiences.md` | A table: audience, what they ask, what makes them act, hook. Then tone and the action we want |
| `messages.md` | Five messages, then the facts table: #, claim, value, as of, public source URL |
| `brand.md` | Colour, type, logo (public URLs), on-screen data style, presenter, voice, sound, end card |
| `guardrails.md` | "Never say or show" and "Always" lists |
| `video/scripts.md` | Scripts as tables: time, Lee says, on screen, b-roll. Each with goal, facts used and caption |
